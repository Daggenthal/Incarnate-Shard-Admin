                    Machines
                    
      
                    Run the shard on another computer (a Steam Machine, a Linux PC or server on your network) and control it from this window. Pick it at the top. The source stays here: starting, building and saving settings copy it over first (tools/remote-shard.sh, over ssh). Nothing new listens on the network: this window reaches the machine through ssh.
